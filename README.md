# Swapna K Y - Personal Portfolio

A modern, responsive personal portfolio website built to showcase my skills, projects, education, and experience as a Computer Science Engineering student and Developer.

## 🚀 Live Demo
**👉 [View Live Portfolio](https://Swapna-KY.github.io/Portfolio/)**

## ✨ Features
* **Modern & Premium Design:** Dark mode aesthetics with glassmorphism effects, smooth gradients, and micro-animations.
* **Fully Responsive:** Adapts perfectly to desktops, tablets, and mobile devices using CSS Grid and Flexbox.
* **Functional Contact Form:** Direct email messaging implemented securely using EmailJS without needing a backend.
* **Dynamic Sections:** Interactive project filters, animated reveal-on-scroll effects, and floating badges.

## 🛠️ Technologies Used
* **HTML5:** Semantic structure and content organization.
* **CSS3:** Custom styling, variables, Flexbox, Grid, animations, and media queries (No external frameworks used for maximum control).
* **JavaScript (Vanilla):** DOM manipulation, scroll events, mobile menu toggling, IntersectionObserver for animations, and form validation.
* **EmailJS:** Third-party service for handling contact form submissions directly from the browser.

## 📁 Sections
* **Hero:** Introduction, full-width profile photo with floating stats.
* **About:** Brief background and soft skills.
* **Skills:** Technical proficiencies (Java, Python, React, SQL, IoT, etc.).
* **Experience & Education:** Timeline of academic and professional history.
* **Projects:** Filterable grid of key projects with direct links.
* **Contact:** Direct email form and social links.

## ⚙️ Setup & Local Usage
To view this project locally:
1. Clone the repository: `git clone https://github.com/Swapna-KY/Portfolio.git`
2. Open the folder: `cd Portfolio`
3. Simply double-click on `index.html` to open it in your default web browser.
